# 작업판

상태: `대기` → `진행` → `검토요청` → `완료` (또는 `수정요청`)
상태는 담당 팀이 바꾸고, `완료`·`수정요청`은 팀장만 바꾼다.
형식: A 유튜브(가로·음성) / B 쇼츠(세로) / C 사진 영상 / 공통 — 사양은 `FORMATS.md`

## 공통 준비

| ID | 작업 | 형식 | 담당 | 상태 | 선행 | 비고 |
|---|---|---|---|---|---|---|
| T00 | 기획서 작성 (`brief/BRIEF.md`) | 공통 | 팀장 | 진행 | — | 감독 답변 대기 |
| T01 | 스토리보드 + 대본 (`STORYBOARD.md`, `SCRIPT.md`) | 공통 | 팀장 | 대기 | T00 | |
| T02 | 스타일 가이드 (색·글꼴·분위기) | 공통 | 팀2 | 대기 | T00 | `assets/generated/style/STYLE.md` |
| T03 | Remotion 프로젝트 설정 (가로·세로 컴포지션 틀) | 공통 | 팀1 | 대기 | T00 | `src/` |
| T04 | 음성 처리 파이프라인 (잡음 제거·-14 LUFS·덕킹·받아쓰기) | 공통 | 팀1 | 대기 | T03 | ffmpeg + Whisper |
