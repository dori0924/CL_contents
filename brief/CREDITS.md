# 음악·소재 출처

## 작품 #1 음악 — YouTube 오디오 보관함에서 (11/21 감독 결정)

YouTube 오디오 보관함은 YouTube 스튜디오 로그인이 필요해 팀장이 직접 받을 수 없다. 아래 순서로 감독이 받는다.

1. https://studio.youtube.com → 왼쪽 **오디오 보관함**
2. 필터: **저작자 표시 필요 없음**(Attribution not required)
3. 검색어 순서대로 들어보고 **처음 3초 안에 신나는 곡**을 고른다
   - `Jingle Bells` → `Christmas` → `Holiday`
   - 분위기 필터: **Happy / Bright**
   - 길이: **1분 30초 ~ 2분 30초** (더 길면 영상이 사진 수에 맞춰 일찍 끝나고 음악이 자연스럽게 줄어든다)
   - 첫 후보: **"12 Days of Christmas (Instrumental)" — Jingle Punks** (오디오 보관함에 있는 것을 확인함. 템포가 느리면 다음 후보로)
4. 다운로드한 파일을 `assets/raw/music/`에 넣고 아래 표에 제목·작가를 적는다.

박자는 영상 코드가 자동으로 분석하므로 어떤 곡을 골라도 된다(70~180 BPM).

### 참고: 다른 무료 음원 (오디오 보관함에 마음에 드는 곡이 없을 때)

조건: 빠르고 밝은 크리스마스 곡, 약 1분 30초~2분 30초, **가족 단톡방·유튜브에 올려도 되는 라이선스**.

| 순위 | 출처 | 찾는 방법 | 라이선스 | 비고 |
|---|---|---|---|---|
| 1 | **YouTube 오디오 보관함** | YouTube 스튜디오 → 오디오 보관함 → 검색 "Christmas" 또는 "Jingle", 분위기 "Happy/Bright" | 무료, 대부분 저작자 표시 불필요 (곡마다 확인) | 유튜브에 올릴 때 가장 안전 |
| 2 | OpenGameArt "Jingle Bells Christmas Song" | https://opengameart.org/node/107904 | CC0로 표시됨 (연주자 미상 → 사용 전 페이지 확인) | 무료 |
| 3 | 유료 음원 사이트 (Artlist, Motion Array 등) | "Jingle Bells upbeat" 검색 | 구독·구매 필요 | 품질 높음 |

- 시중 가수 음원(캐럴 앨범 등)은 저작권 때문에 쓰지 않는다. 유튜브에 올리면 차단·수익 제한될 수 있다.
- 곡을 고르면 파일을 `assets/raw/music/`에 두고(커밋 안 함) 아래 표에 기록한다.
