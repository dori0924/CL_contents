# 우리가족 영상·모션그래픽 프로젝트

가족 영상이나 모션그래픽을 세 AI 팀이 나눠 만든다.

만드는 영상: **A. 음성이 들어간 유튜브 영상(가로)**, **B. 쇼츠(세로)**, **C. 사진으로 만드는 영상**.
종류별 화면 사양, 음성·자막 기준, 팀별 할 일은 [`FORMATS.md`](FORMATS.md)에 있다.

## 팀 구성

| 역할 | 담당 | 주 업무 |
|---|---|---|
| **팀장** | Claude (Claude Code) | 기획·대본(내레이션)·스토리보드, 사진 선별, 자막 교정, 유튜브 제목·설명, 작업 분배, 검토 |
| **팀 1** | ChatGPT Codex | 코드로 만드는 작업: 모션그래픽(Remotion), 컷 편집, 음성 정리·음량 맞춤, 받아쓰기·자막, 사진 슬라이드쇼, ffmpeg 렌더 |
| **팀 2** | Gemini Antigravity | 시각 작업: 스타일 가이드, 타이틀·이름표·스티커 그래픽, 유튜브 썸네일, 브라우저 미리보기로 화면 검수 |
| **감독** | 사용자 | 방향 결정, 원본 소재 제공, 최종 승인 |

세 AI는 서로 직접 대화하지 못한다. **이 폴더의 파일이 소통 창구**이고, 사용자가 각 도구에서 "작업판 보고 내 일 해줘"라고 전달한다.

## 작업 흐름

```
1. 기획    팀장   brief/BRIEF.md 작성 → 감독 승인
2. 설계    팀장   brief/STORYBOARD.md(장면표) + board/TASKS.md에 작업 배정
3. 제작    팀1·팀2 각자 배정된 작업 수행 → board/handoffs/에 인계서 작성
4. 검토    팀장   인계서·결과물 확인 → 수정 요청 또는 통과
5. 통합    팀1    최종 렌더 → output/
6. 승인    감독   시사 후 확정
```

## 폴더 구조

```
CL_contents/
├── CLAUDE.md            ← 팀장(Claude) 지침
├── README.md            ← 이 문서 (팀 규칙)
├── FORMATS.md           ← 영상 종류별 사양·분업 (유튜브/쇼츠/사진 영상)
├── AGENTS.md            ← 팀 1(Codex) 지침  ※ 공통 규칙 포함
├── GEMINI.md            ← 팀 2(Antigravity) 지침
├── .agent/rules/        ← Antigravity 작업공간 규칙 (GEMINI.md와 동일 내용 요약)
├── brief/
│   ├── BRIEF.md         ← 기획서 (무엇을, 왜, 얼마나)
│   ├── STORYBOARD.md    ← 장면별 구성표
│   ├── SCRIPT.md        ← 내레이션 대본·화면 문구
│   ├── PHOTO_PLAN.md    ← 사진 영상의 묶음·배치 계획
│   └── CREDITS.md       ← 음악·소재 출처
├── board/
│   ├── TASKS.md         ← 작업판 (누가 무엇을, 상태)
│   ├── HANDOFF_TEMPLATE.md
│   └── handoffs/        ← 작업 완료 인계서
├── assets/
│   ├── raw/             ← 가족 원본 (Git 제외): photos/ videos/ music/ voice/
│   └── generated/       ← 팀 2 그래픽·썸네일, voice/(AI 음성)
├── src/                 ← 팀 1의 Remotion·스크립트 코드
└── output/              ← 렌더 결과물 (Git 제외)
```

## 공통 규칙

1. **작업판이 기준이다.** `board/TASKS.md`에 배정되지 않은 일은 하지 않는다. 필요해 보이면 작업판 "제안" 칸에 적는다.
2. **자기 구역만 고친다.** 팀 1은 `src/`, 팀 2는 `assets/generated/`, 팀장은 `brief/`·`board/`. 다른 구역은 인계서로 요청한다.
3. **끝나면 인계서.** `board/handoffs/T<번호>_<팀>.md`에 무엇을 만들었고, 어디 있고, 남은 문제가 무엇인지 적는다.
4. **개인정보.** 가족 얼굴·이름·주소·학교 등이 담긴 원본은 `assets/raw/`에만 두고 커밋하지 않는다. 외부 서비스에 올릴 때는 감독 승인을 받는다.
5. **사양 통일.** 종류별 사양은 `FORMATS.md`를 따른다. 가로 1920×1080, 세로 1080×1920, 30fps, H.264 MP4, 음량 -14 LUFS.
6. **가족 목소리.** 녹음 원본은 커밋하지 않는다. AI로 가족 목소리를 흉내 내는 음성 복제는 감독 승인 없이 하지 않는다.

## 기술 스택 (기본안)

- 모션그래픽: [Remotion](https://www.remotion.dev/) (React로 영상 제작) — 팀 1
- 편집·변환·음량 맞춤: ffmpeg — 팀 1
- 받아쓰기(자막): Whisper 계열 — 팀 1
- 이미지·스타일: Antigravity의 이미지 생성 + 브라우저 검수 — 팀 2

기획이 확정되면 팀장이 필요에 맞게 바꾼다.
